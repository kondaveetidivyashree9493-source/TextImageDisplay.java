
# Text and Image Display Using JavaFX

## Aim
To create a JavaFX GUI that displays a text label and an
image using the ImageView component.

## Description
This program creates a window with the title
"Text and Image Display".

It displays the text "Hello, JavaFX!" and an image
arranged vertically using a VBox layout.

## Components Used
- Stage: Creates the window.
- Scene: Holds the GUI components.
- Label: Displays text.
- Image: Loads the image file.
- ImageView: Displays the image.
- VBox: Arranges components vertically.

## Requirements
- Java JDK
- JavaFX SDK
- Java IDE such as IntelliJ IDEA or Eclipse
- image.jpg file

## How to Run
1. Configure JavaFX in your IDE.
2. Save the code as TextImageDisplay.java.
3. Keep image.jpg in the working directory.
4. Compile and run the program using your IDE's
   JavaFX configuration.

## Output
A window titled "Text and Image Display" appears.
It displays "Hello, JavaFX!" and an image vertically.

Window size: 600 x 400 pixels.

## Result
Successfully created a JavaFX GUI using Label,
ImageView, VBox, Stage, and Scene.
